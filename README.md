# Suivi TKD — assistance et confidentialité

Suivi TKD est une application de suivi pour taekwondoïstes de combat (règles World Taekwondo) : objectifs d'entraînement, analyse des combats action par action et fiches de scouting des adversaires.

## Assistance

Une question, un problème ou une suggestion : écris à **[ton e-mail]**.
Indique ton modèle d'iPhone, la version d'iOS et ce que tu faisais quand le problème est apparu.

**Questions fréquentes**

- **Faut-il un compte ?** Non. L'application fonctionne sans compte et sans connexion internet.
- **Comment sauvegarder mes données ?** Onglet Données → « Export complet (JSON) ». Garde le fichier (Fichiers, iCloud Drive, e-mail).
- **Comment récupérer mes données sur un autre appareil ?** Onglet Données → « Choisir un fichier JSON », puis sélectionne ton export.
- **Comment envoyer mes mesures à mon coach ?** Onglet Données → « Mesures (CSV) », qui s'ouvre dans Excel ou Numbers.
- **Comment tout effacer ?** Onglet Données → « Tout effacer », ou supprime l'application.

## Politique de confidentialité

*Dernière mise à jour : 17 octobre 2026*

**Aucune donnée n'est collectée.** Suivi TKD n'a ni compte utilisateur, ni publicité, ni outil de mesure d'audience, ni traçage.

- **Tes données restent sur ton appareil.** Objectifs, mesures, combats, fiches d'adversaires et bilans sont enregistrés uniquement dans le stockage local de l'application. Ils ne sont envoyés à aucun serveur.
- **Vidéos.** Une vidéo que tu choisis sur ton appareil reste sur ton appareil. Un lien YouTube que tu ajoutes est lu avec le lecteur officiel de YouTube : pendant la lecture, YouTube (Google) peut traiter des données selon sa propre politique de confidentialité (https://policies.google.com/privacy).
- **Exports.** Les fichiers JSON et CSV ne sont créés que lorsque tu le demandes, et tu choisis toi-même avec qui les partager.
- **Suppression.** « Tout effacer » dans l'onglet Données, ou la suppression de l'application, efface toutes tes données.
- **Enfants.** L'application ne collecte aucune donnée, y compris celles des mineurs.
- **Évolutions.** Si une future version ajoute une fonction en ligne (par exemple la synchronisation entre appareils), cette politique sera mise à jour avant sa mise à disposition.
